# Security Policy

## Supported versions

The `main` branch and the latest published PyPI release of `shardguard` receive security fixes.

## Reporting a vulnerability

Please open a **private** security advisory on the GitHub repository, or email the maintainer listed on the project page. Do not file a public issue for undisclosed vulnerabilities.

Include:

- Affected version / commit
- Reproduction steps
- Impact assessment (if known)

We aim to acknowledge reports within a reasonable time and coordinate disclosure.
